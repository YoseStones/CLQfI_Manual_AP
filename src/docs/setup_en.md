# Prerequisites

    - Archipelago: https://github.com/ArchipelagoMW/Archipelago/releases
    - Code Lyoko: Quest for Infinity Manual APWorld (Look for releases)
    - Poptracker for this game in order to have a better experience (Look for releases)
    - Have a way to play this game, that will be covered in the next point

## Required Software to play

There are two ways to play this game:
    - Having an original console with an original copy of the game (Any region), have in mind that it is only available for Wii, PS2 and PSP consoles.
    - Dumping an original copy of the game (a.k.a. The legal way to obtain the rom file) and an emulator of your preference (Dolphin, PCSX2, PPSSPP)
Once you have the game, it's important to beat it so every level can be accessed (100% is not required, in fact, the less collectables you have gotten, the better it gets)

## Installation Procedures

For Manual Client:
    - Put the `clqfi_manual.apworld` file in the `custom_worlds` folder of your Archipelago installation. You can also just double-click the file to automatically install it.
For Poptracker:
    - Put the `CLQfIpoptracker` folder in the `packs` folder of your Poptracker installation.

## Game Troubleshooting

    - Combat logic and Bosses were not checked at 100% so maybe you may experience that you'll need certain character to get pass. Let me know if that happens.
    - It's a pretty short game, having the duration of a Metroid game. So I won't recommend to play this with long games like Zelda or SA2 to avoid get BK'ed constantly
    - Most of the checks are pretty strict so it is highly recommended to use the Poptracker (It has full compatibility with the APWorld)
    - Poptracker can't give the "Victory" item, so you need to use the Manual Client instead.
